# Hướng Dẫn Thư Mục Hình Ảnh (Images) — Đắk Lắk Di

Thư mục này dùng để lưu trữ toàn bộ hình ảnh phục vụ cho giao diện Frontend.

## 1. Cách Gọi Ảnh Trong Code
Mọi tệp ảnh đặt tại `frontend/public/images/` có thể được gọi trực tiếp trong React với đường dẫn bắt đầu bằng `/images/`:
```jsx
<img src="/images/placeholders/hero-banner.jpg" alt="Đắk Lắk Di" />
```
